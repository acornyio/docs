# Chinese (zh) Multilingual Support — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Simplified Chinese (`zh-CN`) as a second language for the Acorny Help Center, with a language switcher and full translations of all 26 English pages plus a Chinese homepage, and SEO parity (structured data, breadcrumbs, hreflang).

**Architecture:** Starlight-native i18n via a `root` locale (English, no URL change) + a `zh` locale (content under `src/content/docs/zh/`, URLs prefixed `/zh/`). The existing built-in `LanguageSelect` (already wired into `Header.astro` and `MobileMenuFooter.astro`) activates automatically. The custom `scripts/inject-structured-data.mjs` is made locale-aware so Chinese pages keep JSON-LD/breadcrumb parity.

**Tech Stack:** Astro 6, Starlight 0.39, @astrojs/sitemap, node:test. All work is in the worktree at `.worktrees/feat-i18n-zh` on branch `feat/i18n-zh`.

**Spec:** `docs/superpowers/specs/2026-06-26-i18n-zh-design.md`

## Translation conventions (apply to EVERY content task below)

Hard rules every translated page MUST follow:

1. **Create the file at the mirrored path:** `src/content/docs/<section>/<page>.md` → `src/content/docs/zh/<section>/<page>.md`.
2. **Translate frontmatter `title` and `description`.** Keep all other frontmatter keys (`template`, `hero`, `sidebar`, `badge`, etc.) and translate display strings inside them (e.g. `hero.title`, `hero.tagline`, `hero.actions[].text`).
3. **Internal links MUST be prefixed with `/zh/`.** Starlight does NOT auto-localize markdown body links. Example: English `[Quick start](/getting-started/quick-start/)` becomes `[快速开始](/zh/getting-started/quick-start/)`. Every link keeps its trailing slash.
4. **Preserve structure exactly:** same heading hierarchy (`##`, `###`), same numbered lists, same code blocks/fences, same blockquotes, same table layout, same inline code.
5. **Reuse the same images** — identical paths, e.g. `![…](/images/quick-start/step1-toolbar.png)`. Translate the alt text. Do not add or remove images.
6. **Keep technical tokens untranslated inside code/inline-code:** `My Clippings.txt`, `==========`, `weread-export.json`, `api/v2/highlights`, file names, URLs, setting names shown as code.
7. **Apply the glossary** consistently (see spec/§3): Highlights→高亮, Recall cards→复习卡, Spaced repetition→间隔重复, Import→导入, Sync→同步, Review→复习, Browser extension→浏览器扩展, Source→来源, Token→令牌, Highlights list→高亮列表.
8. **Do not touch any English file.** English content is the read-only reference.

**Reference exemplar:** Task 4 produces the fully-translated `zh/index.md`. Follow its exact conventions for every other page.

  const relativePath = path.relative(contentRoot, filePath).replaceAll(path.sep, '/')

## 核心概念

**高亮（Highlight）：** 你从文章、书籍、PDF 或阅读 App 中保存的文本。

**来源（Source）：** 高亮所出自的文章、书籍、订阅条目或文件。

**复习卡（Recall card）：** 由高亮生成的复习提示，让你练习记住观点，而不仅仅是重读它。

**间隔重复（Spaced repetition）：** 一种排程方法——当你记住内容时，间隔会逐渐变长；当你感到吃力时，会更早再次出现。

**导入（Import）：** 从导出文件或兼容 API 进行的一次性转移。

**同步（Sync）：** 一种持续连接，可以从其他服务拉取新高亮。
