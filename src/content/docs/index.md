Acorny is a Readwise alternative for readers who want their highlights to become something they can remember. It helps you capture highlights from web pages and supported reading tools, import older notes from files or connected services, and review important ideas as recall cards with spaced repetition.

Use this Help Center when you want to set up Acorny, migrate an existing highlight library, understand review sessions, or fix a sync problem.

## Core concepts

**Highlight:** Text you saved from an article, book, PDF, or reading app.

**Source:** The article, book, feed item, or file a highlight came from.

**Recall card:** A review prompt generated from a highlight so you practice remembering the idea instead of only rereading it.

**Spaced repetition:** A scheduling method that shows material again after increasing intervals when you remember it and sooner when you struggle.

**Import:** A one-time transfer from an export file or compatible API.

**Sync:** An ongoing connection that can pull new highlights from another service.
