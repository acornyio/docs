Acorny 是一款面向读者的 Readwise 替代品，帮助你把高亮变成真正能记住的内容。它让你从网页和受支持的阅读工具中捕获高亮，从文件或已连接的服务导入旧笔记，并通过间隔重复把重要观点变成复习卡来复习。

当你想要设置 Acorny、迁移现有的高亮库、了解复习会话，或解决同步问题时，请使用本帮助中心。

## 核心概念

**高亮（Highlight）：** 你从文章、书籍、PDF 或阅读 App 中保存的文本。

**来源（Source）：** 高亮所出自的文章、书籍、订阅条目或文件。

**复习卡（Recall card）：** 由高亮生成的复习提示，让你练习记住观点，而不仅仅是重读它。

**间隔重复（Spaced repetition）：** 一种排程方法——当你记住内容时，间隔会逐渐变长；当你感到吃力时，会更早再次出现。

**导入（Import）：** 从导出文件或兼容 API 进行的一次性转移。

**同步（Sync）：** 一种持续连接，可以从其他服务拉取新高亮。
