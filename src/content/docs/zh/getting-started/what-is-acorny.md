---
title: Acorny 是什么？
description: 了解 Acorny 的功能、它与 Readwise 的对比，以及高亮如何变成复习卡。
---

Acorny 是一款 Readwise 替代品，帮助你捕获高亮并通过间隔重复来复习。它专为那些已经保存了有用段落、但希望找到一种实用方法来日后记住并复用这些想法的读者而设计。

大多数高亮工具止步于存储。Acorny 关注的是下一步：把保存的文本变成复习卡，为这些卡片排程，并帮助你随着时间推移练习这些想法。

## Acorny 能帮你做什么

Acorny 支持三项相互关联的工作：

1. 使用浏览器扩展从网页捕获高亮。
2. 从受支持的阅读工具导入或同步高亮。
3. 把保存的想法作为复习卡来复习。

你可以从保存一条网页高亮这样的小事做起，也可以从 Readwise、Kindle、Moon+ Reader、Cubox、Diigo、PDF、CSV 或兼容的导入 API 等来源迁移现有高亮库。

## Acorny 与笔记应用有何不同

笔记应用擅长组织写作、项目和长期参考资料。Acorny 的范围更窄。它让高亮始终关联其来源，然后使其可供复习。

因此，当你关心以下这类问题时，Acorny 就能派上用场：

- 这本书里哪些想法我应该记住？
- 我最近复习过哪些高亮？
- 哪些段落已经可以变成复习卡？
- 我如何防止旧高亮消失在归档中？

## Acorny 与 Readwise 的对比

Readwise 普及了收集高亮并重新呈现它们的工作流。Acorny 追随同样的总体目标，但它是围绕 Acorny 自身的导入、同步和复习体验构建的。

当你想要以下功能时，请使用 Acorny：

- 一个能接收多种导出格式数据的高亮库。
- 围绕复习卡构建的复习会话。
- 一款公开测试版（Beta）产品，其中保存的高亮始终是体验的核心。
- 一种可以从文件、浏览器高亮或已连接的服务开始的工作流。

如果你正在从 Readwise 迁移，请从[从 Readwise 导入](/zh/import-sync/readwise/)开始。如果你仍在比较各款工具，请阅读[复习会话如何运作](/zh/review-recall/how-review-works/)和[间隔重复如何运作](/zh/review-recall/how-spaced-repetition-works/)。

## 高亮会发生什么

当一条高亮进入 Acorny 时，它归属于某个来源。来源可能是网页、书籍、订阅条目或导入的文件。当来源提供时，Acorny 会保留高亮文本以及任何受支持的元数据，例如标题、URL、作者、笔记、标签、日期或位置。

之后，该高亮会出现在你的库中并符合复习条件。复习会话会显示复习卡，让你练习记住这个想法。你的评分会告诉 Acorny 这张卡片应该更早返回，还是等待更长的复习间隔。

## 何时 Acorny 可能不是合适的工具

Acorny 不是一款通用的书签管理器、完整的写作工作区，也不是每个阅读应用的替代品。它不保证每个第三方导出文件中的每个字段都能转移。针对各来源的专属指南说明了 Acorny 能为每个来源保留哪些内容。

如果你主要需要一个可搜索的归档，你可能仍然需要在 Acorny 之外搭配一款笔记应用。如果你希望高亮变成可复习的记忆提示，Acorny 正是为此工作流而设计的。
