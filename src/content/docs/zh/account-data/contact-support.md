当某篇帮助文章无法解决你的问题、而你需要联系 Acorny 支持时，请使用本页面。

## 联系支持之前

请先查看相关的故障排查页面：

- 保存或导入的高亮缺失：[高亮未显示](/zh/troubleshooting/highlights-not-showing/)
- 导入与同步失败：[排查导入与同步问题](/zh/import-sync/troubleshooting/)
- 账户访问：[账户安全](/zh/account-data/account-security/)

如果问题仍然存在，请收集下方这些信息。清晰的信息更容易判断问题是文件格式问题、已连接的提供方问题、账户问题，还是复习排程问题。

## 应包含的信息

请包含：

- 来源名称，例如 Readwise、Kindle、Moon+ Reader、Cubox、Diigo、Instapaper、Inoreader 或 Browser extension（浏览器扩展）。
- 你尝试的操作，例如上传文件、连接提供方、手动同步、保存高亮或开始复习。
- Acorny 中显示的确切错误信息。
- 问题是否只影响某一条高亮、某一个文件、某一个提供方，还是影响每一条高亮。
- 如果问题涉及扩展，请提供浏览器和操作系统。
- 导入文件的大致大小与行数。

除非支持团队明确要求提供经过脱敏处理的样本，否则不要发送密码、API 密钥、访问令牌、私密 Cookie 或完整的导出文件。

## 安全示例

好的支持消息：

> 我导入了一份大约 1,200 行的 Diigo CSV。预览显示 900 条高亮和 300 行被跳过。我原本期望便利贴会附在来自同一页面的高亮上。来源名称是 Diigo，文件来自 Diigo 的 CSV 导出。

好的支持消息：

> 我连接了 Inoreader 并运行了手动同步。Acorny 报告导入了零条高亮。Inoreader 账户中包含已批注的条目，而我今天才授权了 Acorny。

## 不要发送的内容

不要发送密码。不要发送 Readwise API 令牌。不要发送 OAuth 访问令牌。不要发送显示私密账户凭证的截图。

如果截图有帮助，请裁剪或模糊账户邮箱、令牌、私密文章标题和私密笔记。
