## 支持的来源

### 文件与本地导入

Acorny 支持微信读书 JSON、Readwise CSV、Moon+ Reader 文件、Cubox JSON、Diigo CSV、Kindle 的 `My Clippings.txt`、带批注的 PDF，以及 Acorny 的 JSON 或 CSV 导出。

### 一次性 API 导入

Readwise 和 Diigo 可以通过它们的 API 进行一次性导入。

### 持续同步

Instapaper 和 Inoreader 是目前的持续同步服务。Koodo Reader、Moon+ Reader 和 Readest 可以使用 Import API 令牌，通过 Acorny 的 Readwise 兼容端点推送高亮。

## 复习卡与评分

Acorny 会把保存的高亮变成复习卡。复习会让你在重读之前先回忆这个想法，然后为结果评分。

## 隐私与数据导出

Acorny 会存储提供高亮、导入、同步和复习功能所需的高亮内容与账户数据。自助式数据导出目前还不是公开的帮助中心流程。如果你需要数据副本，请联系支持。

## 常见问题

**Acorny 还处于 Beta 阶段吗？** Acorny 目前处于公开 Beta。具体到账户的可用性与定价，请以产品内的最新信息为准。

**Acorny 会取代 Readwise 吗？** Acorny 专注于复习卡和复习会话。在导入整个库之前，先从小规模迁移开始。

**为什么保存的高亮还没出现在复习里？** 高亮可能先在你的库中，之后才到期。先查看高亮列表，等卡片到期后再回来。
