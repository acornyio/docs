---
title: 导入 Acorny 导出文件
description: 从 Acorny 的 JSON 或 CSV 导出文件还原高亮。
---

当你已经拥有一个从 Acorny 导出的文件，并希望还原它或将其移入另一个 Acorny 账户时，请使用 Acorny 导出文件导入。

## 受支持的文件

Acorny 在导入界面中接受其自身导出的 JSON 和 CSV 文件。

当你希望获得最完整的结构化数据时，请使用 JSON。当你需要一个与电子表格兼容的文件，或在重新导入前手动编辑过行时，请使用 CSV。

## 导入流程

1. 打开 Acorny，然后进入 Import。
2. 选择 Upload File。
3. 将 Source type 设为 Acorny Exported File，或将 Source type 保持为 Auto-detect。
4. 上传 JSON 或 CSV 导出文件。
5. 查看预览。
6. 选择 Confirm import。

## 重复处理

如果某条导出的高亮已经存在于你的库中，Acorny 会跳过该重复项，而不是创建另一份副本。这使得在网络错误或部分迁移后重新尝试导入是安全的。

## 何时改用提供方专属导入

如果该文件直接来自其他服务，请先选择该提供方。提供方专属导入可以比通用 CSV 文件保留更多元数据。
