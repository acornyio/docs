Use the Acorny browser extension when you want to capture a passage without leaving the page you are reading.

## Supported browsers

| Browser | Current status | Where to get it |
| --- | --- | --- |
| Chrome | Available | [Chrome Web Store](https://chromewebstore.google.com/detail/acorny/khakobfdacgdecadkjcplkmnmlfdejbp) |
| Microsoft Edge | Available | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/acorny/bgnjnddcflalagpkjjlbhjinljnjmnkk) |
| Firefox | Available | [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/acorny/) |
| Safari | Planned | Not available yet |

## 1. Install and sign in

Install the extension for your browser. If the icon is hidden after installation, open the browser's extensions menu and pin Acorny to the toolbar. Sign in to the same Acorny account that you use on the web app.

![Acorny browser extension toolbar button](/images/quick-start/step1-toolbar.png)

## 2. Save a highlight

1. Open a normal web page with selectable text.
2. Select the passage you want to keep.
3. Open Acorny from the browser toolbar and save the selected passage.

The popup shows the selected text before you save it, so check that the passage and source page are the ones you intended to capture.

![Acorny browser extension popup for saving a highlight](/images/quick-start/step2-popup.png)

## 3. Confirm the highlight reached your library

Open Acorny and check the Highlights list. The saved passage should appear with its source context. If it is present, capture is working and the highlight is ready for the [review workflow](/review-recall/how-review-works/).

![Acorny highlights list showing saved highlights](/images/quick-start/step3-list.png)

## Permissions

The extension needs access to the page you are using so it can read the selected text and source URL when you explicitly save a highlight. It does not need you to hand over a separate provider export file for normal web capture.

## If saving fails

- Confirm that the web app and extension are signed in to the same Acorny account.
- Reload the page, select the passage again, and reopen the extension.
- Try a normal article page if the current site blocks text selection or browser extensions.
- If the save completes but you cannot find the result, follow [Highlights are not showing up](/troubleshooting/highlights-not-showing/).

For highlights already stored in another service or reader, compare the current options in [Import vs sync](/import-sync/overview/).
