---
title: Browser extension
description: Use the Acorny browser extension to save web highlights.
---

The browser extension lets you save highlights from web pages into Acorny.

## Save a highlight

Select text on a web page, open the Acorny extension, and save the highlight.

## Permissions

The extension needs access to the page you are using so it can read the selected text and source URL when you explicitly save a highlight.

## If saving fails

Make sure you are signed in, reload the page, and try saving again. If the page blocks extensions or selection tools, copy the text and add it through another import path.
