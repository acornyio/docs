---
title: Run a manual sync
description: Manually retry a connected integration sync in Acorny.
---

Manual sync is useful when you just connected a provider or when a previous sync failed.

## Run sync

Open Extensions & Apps, find the connected provider, and choose Sync now or Retry sync.

## Read the result

Acorny reports how many highlights were imported, skipped, or failed. A result of zero imported items can be normal when the provider has no new highlights.
