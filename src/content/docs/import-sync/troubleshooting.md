---
title: Troubleshoot import and sync issues
description: Fix common import and sync problems in Acorny.
---

Use this page when a file import or connected sync does not bring in the highlights you expected.

## File import fails

Check that the file matches the source you selected. For example, a Cubox JSON export should be imported as Cubox, while a Diigo CSV export should be imported as Diigo.

For Cubox, use the JSON file generated by Cubox Exporter. For WeRead, use `weread-export.json` from the Acorny browser extension. For Kindle, use the original `My Clippings.txt` file from the Kindle device.

## Preview shows fewer highlights than expected

Some exports contain bookmarks, empty annotations, or notes without highlighted text. Acorny imports highlight text and may skip items that cannot become reviewable highlights.

## Sync imports zero highlights

Confirm that the connected account actually contains highlights or annotations, then run a manual sync. Some providers expose notes and highlights differently.

Moon+ Reader push sync is configured inside Moon+ Reader, not from an Extensions & Apps card. If new Moon+ Reader highlights do not appear, verify the Readwise URL and Import API token in Moon+ Reader's Readwise sync settings.

## Still blocked

Contact support with the source name, file type, and the error shown in Acorny. Do not send passwords or API keys.
