---
title: Import from Cubox
description: Import Cubox highlights from a Cubox JSON export.
---

Use Cubox import when your highlights are stored in Cubox and you want to move them into Acorny.

Cubox does not upload directly to Acorny. First export a Cubox JSON file with Cubox Exporter, then upload that JSON file on the Acorny import page.

Before using Cubox Exporter, enable the Cubox API extension and copy the API value it provides.

![Cubox settings page with API extension enabled](/images/import-sync/cubox/cubox-api.png)

## Export from Cubox

1. Download Cubox Exporter:
   - [GitHub releases](https://github.com/momadacoding/cubox-exporter/releases)
   - [Gitee mirror](https://gitee.com/acorny_0/cubox-exporter/releases)
2. Open Cubox Exporter on your computer.
3. Follow the exporter instructions to sign in or provide the Cubox access information it requires.
4. Export your Cubox data as JSON.
5. Keep the generated JSON file. It should contain articles and their nested highlights.

Do not upload a random Cubox backup or browser download. Acorny expects the JSON shape produced by Cubox Exporter: `source: "cubox"` with an `articles` array.

![Cubox Exporter tool for exporting highlights to JSON](/images/import-sync/cubox/cubox-exporter-tool.png)

## Import into Acorny

1. Open Acorny, then go to Import.
2. Choose Upload File.
3. Set Source type to Cubox JSON.
4. Upload the JSON file generated by Cubox Exporter.
5. Review the preview counts and sample records.
6. Choose Confirm import.

Acorny imports each non-empty Cubox highlight as a highlight record. It preserves article title, source URL, article tags, highlight note, Cubox article ID, Cubox highlight ID, Cubox highlight URL, domain, color, and created time when the export contains those fields.

## What transfers

Cubox import can preserve:

- Highlight text
- Article title
- Source URL
- Domain
- Article tags
- Highlight note
- Cubox article ID
- Cubox highlight ID
- Cubox highlight URL
- Highlight color
- Created time

This makes Cubox import useful for readers who used Cubox as a web annotation library and want those passages to become reviewable in Acorny.

## What does not transfer

Acorny does not import Cubox account settings, subscription state, reading progress, or every Cubox list view. It imports the highlight records that Cubox Exporter writes into the JSON file.

If a Cubox article has no highlight text, it may be a bookmark rather than review material.

## Empty highlights

If a Cubox export contains an empty highlight, Acorny skips that item so your library only contains reviewable text.

## Preview checks

Before confirming the import, inspect the preview:

1. Confirm the article title is recognizable.
2. Confirm the highlight text is not empty.
3. Confirm notes and tags appear when you expect them.
4. Confirm the import count is close to the number of Cubox highlights you exported.

## If import fails

If Acorny says the format is unsupported, confirm that the file came from Cubox Exporter and was not manually edited. If the exporter cannot run in your environment, use the Gitee mirror link above or retry from another computer.

If the JSON file is very large, try exporting a smaller Cubox set first. A small successful import is easier to inspect than a full-library import with thousands of records.
