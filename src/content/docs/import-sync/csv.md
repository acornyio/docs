---
title: Import from CSV
description: Import highlights with Acorny's general CSV template.
---

Use CSV import when your highlights are not from a provider-specific export or when you converted another format yourself.

## Required idea

Each row should describe a highlight: the quoted text, source title, source URL or another detail that identifies the source, and optional note or tags.

## When to use provider-specific import

If your file came directly from Readwise, Diigo, WeRead, Cubox, Kindle, Moon+ Reader, PDF annotation tools, or Acorny itself, choose that provider first. Provider-specific import can preserve more metadata and usually gives better duplicate handling.

Use generic CSV only when your data does not match one of the provider-specific formats or when you have converted another source into a simple spreadsheet yourself.
